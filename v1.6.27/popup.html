Maker 刷量参数（限价挂单，不吃 spread）

标的：
BTC/ETH 按基础币数量；TradFi 标的按每笔 USDC 名义（qty=名义÷市价），休市时自动跳过。
开仓挂限价单（买 bid-偏移 / 卖 ask+偏移）；超时未成交自动撤单；成交后按止盈/止损/最长持仓市价平仓。PAPER 模式假设限价单立即成交。

Hedge 对冲参数（对子通用，各所可配）

信号：A腿 5 分钟 RSI(12)，<45 做多、>55 做空，45~55 不开仓；每根 5m K线只发一次信号。
对冲：A腿成交后开等额反向 B腿（IOC 吃单）；止盈每腿 ±0.8%（reduce-only 挂单）；任一腿 -15% 或双腿异常则全平。
仓位：每腿名义 ≈ 权益 ×5；两腿杠杆需与交易所预设一致（Arcus 可 API 校验，不一致拒绝启动）。
风控：价差 >10bps 不开仓；日内累计亏损达 50U 当天停止。默认 PAPER（只看信号不下单）。
各所默认对子：Arcus=BTC-USD/ETH-USD(40x/25x)；Variational=BTC/ETH(10x/10x，K线由插件运行积累，首次约需4.5小时)；QFEX=GOLD-USD/SILVER-USD(10x/10x)。Variational 杠杆请在网页端预设，API 无法校验。

Fund 单所费率套利（固定策略）

逻辑：同一所内两个市场的年化费率差。做多低费率腿、做空高费率腿，edge = 高 − 低。
开仓线年化 15%，平仓线 5%；每腿名义 $500，市价双腿同开；基差超 50bps 或 edge 跌破平仓线则两腿全平。
任一腿费率取不到 → 跳过不清仓（防 API 毛刺误平）。默认 PAPER（只看信号不下单）。

XFund 跨所费率套利（固定策略）

逻辑：同一标的在两所的年化费率差。做多低费率所、做空高费率所，edge = 高 − 低。
默认：Variational × Lighter 的 BTC；开仓线年化 10%，平仓线 3%。
每腿名义 $500，先开 long 腿再开 short 腿；第二腿失败立即平掉第一腿（绝不留裸腿）。
基差超 80bps 或 edge 跌破平仓线则两所各平各的；任一所持仓读失败 → 保持不清仓。
默认 PAPER（只看信号不下单）。LIVE 前两所凭证都要配好（Lighter 需官网 API Key）。
三所重叠标的：US100↔US100-USD↔QQQ-USD；US500↔US500-USD↔SPY-USD；BTC/ETH 只有 Variational×Arcus（QFEX 无加密永续）；QFEX↔Arcus 同名：NVDA/AAPL/SNDK-USD。
